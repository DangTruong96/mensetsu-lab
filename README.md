# MensetsuLab

Website luyện phỏng vấn chuyển việc IT tại Nhật theo đúng công ty ứng tuyển.

- Nhập tên công ty, link website / JD, ngành, vị trí, vòng phỏng vấn và ngày phỏng vấn
- AI soạn hồ sơ công ty và bộ câu hỏi riêng theo chủ đề
- Dùng thử miễn phí 30 phút, có báo cáo chấm điểm và sửa keigo
- Gói trả phí: 4.980 yên / 5 buổi — bản free có quảng cáo ngoài phòng luyện

Bản thử nghiệm chạy hoàn toàn trên trình duyệt (không server, không API trả phí).
